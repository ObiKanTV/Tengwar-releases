# Disclaimer

Tengwar is in early access: expect rough edges, and please report what you find at
https://github.com/ObiKanTV/Tengwar-releases/issues.

## What Tengwar does on your PC

Tengwar reads your game controllers through Windows. It never sends input to a game, never presses keys,
and never goes online.

It writes only the game binding files you ask it to install, and before it replaces one it backs the old
file up and checks the copy. Even so, binding files are the games' own files: keep your own copies of
bindings you care about, and check a new layout in the game before you rely on it. Use Tengwar at your
own risk; it is provided as is, without warranty (see [LICENSE](LICENSE)).

**Add a DCS aircraft** reads files from DCS World's install folder and your Saved Games folder, and never
changes them.

## Use of AI

AI tools have been used in making Tengwar:

- to plan its architecture;
- to write code comments;
- to write commit messages;
- to write documentation, including the guides and this page.

What Tengwar does, and how, is decided by its author, who tests it in the games it supports.
